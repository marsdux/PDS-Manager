# PDS-Manager (Personal Data Sheet Manager)

A robust, Desktop-based Java application built using the NetBeans IDE for managing and handling digital Personal Data Sheets (PDS).

## 🚀 Features
- **Secure Storage:** Implements custom cryptographic services to protect user data.
- **Dynamic UI:** Intuitive dashboard with dynamic table panels for tracking work experience, education history, family background, and eligibility entries.
- **Reporting & Exporting:** Generates structured reports and data handling utilities, including CSV support.
- **Document Attachments:** Dedicated attachments panel for handling secure uploads and file management.

## 🛠️ Tech Stack
- **Language:** Java 100%
- **IDE:** NetBeans
- **Build Tool:** Ant
- **Architecture:** Model-View-Controller (MVC) components for clean data flow.

## ⚙️ How to Run
1. Clone this repository.
2. Open the project folder in NetBeans IDE.
3. Clean and Build the project using `build.xml`.
4. Run `Main.java` to start the application.
